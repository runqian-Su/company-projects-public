# 公司项目公开作品集

> 2026.04-2026.07 三个月内，在真实企业业务场景中并行推进的一组 AI-native 产品与数据系统项目。

## 阅读说明

本目录用于展示我在企业内部项目中形成的产品定义、业务建模、数据治理、Agent 编排和 AI 协作实现能力。

这些项目不是多年跨度的传统工程积累，而是在 2026 年 4 月至 7 月期间，围绕多个真实业务问题并行推进、快速建模、快速实现和持续验收形成的项目集。我的主要职责是问题定义、结构设计、上下文组织、AI 协作实现驱动、运行验证和交付复盘。

公开版本只保留脱敏后的架构、合成数据、Demo 代码和说明文档，不包含真实客户数据、内部接口、原始业务文件或运行产物。

## 项目定位

| 项目 | 核心能力 | 公开 Demo 重点 |
| --- | --- | --- |
| `bpo-data-platform` | 企业业务系统架构 / 数据治理 | A/B/Ba/C 分层、Ba 受控操作、API、Skill、可视化同步 |
| `finance-ar-object-platform` | 财务对象建模 / 一致性验证 | 集团、主体、往来对象、单据、应收事实 |
| `tender-agent-workflow` | Agent workflow / 多 worker 编排 | 多 Skill 编排与 Agent 集群汇总去重 |
| `attendance-dirty-data-pipeline` | 脏数据处理 | 多格式表、身份归一、白名单、异常归因 |
| `proposal-generation-skill` | 受约束内容生产 | 资产库、模板库、结构模式、deck JSON、校验 |
| `talent-report-skill` | AI 前端自动化 / 标准报告对象 | resume.raw / insight / report.json / 模板渲染边界 |
